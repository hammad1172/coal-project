# coal-project
Bubble Sorting System (Assembly - Irvine32)

This project is a console-based Bubble Sort implementation in x86 Assembly language using the Irvine32 library. It allows users to input up to 10,000 integers and sort them in either ascending or descending order. The system includes error handling for invalid inputs and provides a user-friendly interface with colored text outputs.

Features:
Accepts up to 10,000 user-input integers.
Allows sorting in ascending or descending order.
Displays both original and sorted arrays.
Offers the option to sort multiple arrays without restarting the program.
Input validation and helpful error messages.
Uses Irvine32 library for I/O operations and display control.
